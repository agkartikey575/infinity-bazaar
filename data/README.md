# Data

The deal engine reads these files. Run `node scripts/validate-data.mjs` after any change.

| File | What it holds |
| --- | --- |
| `catalog.json` | 40 items in 5 groups. Each has a price range, seller cost and hidden-floor range, levers besides price, hidden fees and fitting seller types. Generated by `scripts/gen_catalog.py`. |
| `sellers.json` | 10 seller personalities: opening markup, concession speed, tactics, soft spots, delivery reliability. |
| `events.json` | 10 random events (flash sale, stock-out, rival buyer, failed delivery…) and what each changes. |
| `missions.json` | 3 missions, starting with "PayPal AI Hackathon in 10 days, $300". |

## How a seller is drawn for a deal

1. Pick 3 archetypes from the item's `sellerTypes`.
2. Hidden floor = a point inside `seller.floorRange`, placed by the archetype's `floorBias` (0 = bottom, 1 = top), plus a little noise.
3. Opening price = `price.typical` × a random value inside the archetype's `openMarkup`.
4. Each turn the seller concedes a share of the gap to its floor, using `concessionSpeed`.

## Price confidence

All prices are USD estimates (`confidence: "estimate"`). The app refreshes them with live web search using each item's `verifyQuery` and shows the sources on the price card.
